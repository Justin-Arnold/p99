# Command: version

`p99 version` prints build information for the installed binary.

```sh
p99 version
```

Output includes:

- version
- commit
- build date

## What Problem It Solves

Latency data is only useful when the tool that produced it can be identified.

Use `p99 version` in bug reports, CI logs, release verification, and debugging sessions where multiple machines may have different binaries installed.

## Flags

This command has no flags.
